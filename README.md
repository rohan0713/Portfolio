# Professional Portfolio - Rohan Ramola

A modern, responsive portfolio website showcasing my work as an Android & Flutter Developer.

## Features

- **Responsive Design**: Optimized for all devices.
- **Project Showcase**: Display of key projects like Yatra, Mi-City CEP, and VMS.
- **Skills Section**: Detailed breakdown of languages, frameworks, and tools.
- **Dark/Light Mode**: (If applicable in template)

## Tech Stack

- HTML5, CSS3, JavaScript
- Vercel for Deployment

## How to Update

1.  **Edit Content**: Modify `index.html` to update text, links, or images.
2.  **Styles**: tweak `styles.css` or `mediaqueries.css` for layout changes.
3.  **Images**: Replace files in `assets/` folder.

## Deployment

This project is configured for Vercel.

1.  **Push Changes**:
    ```bash
    git add .
    git commit -m "Update portfolio"
    git push origin master
    ```

2.  **Vercel Dashboard**:
    - Go to your Vercel dashboard.
    - If connected to GitHub, the deployment will trigger automatically.
    - Otherwise, use `vercel` CLI:
      ```bash
      vercel
      ```
